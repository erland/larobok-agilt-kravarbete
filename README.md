# Från XLPM till agilt kravarbete

Detta är ett bokprojekt för en svensk praktisk lärobok/handbok om hur arbetet förändras för personer som fångar, analyserar och dokumenterar funktionella krav när organisationen rör sig från XLPM- eller fasbaserat arbetssätt till mer agil, iterativ och teamnära utveckling.

## Projektstruktur

```text
fran-xlpm-till-agilt-kravarbete-projekt/
├── README.md
├── docs/
├── chapters/
├── exercises/
├── examples/
├── code/
├── assets/
└── exports/
```
