# Övningar till kapitel 9: Spårbarhet utan att skapa dokumentationsbörda

## Övning 1: Bedöm spårbarhetsnivå

Välj tre funktionella krav. Bedöm för varje krav om spårbarhetsnivån bör vara låg, normal eller hög.

Använd frågorna:

1. Vad händer om kravet blir fel?
2. Finns regel-, säkerhets-, juridik- eller revisionspåverkan?
3. Hur många andra krav eller systemdelar kan påverkas?
4. Behöver beslutet kunna förklaras i efterhand?
5. Hur sannolikt är det att kravet ändras?

## Övning 2: Skapa ett beslutsspår

Skriv ett kort beslutsspår för ett krav där teamet valt mellan två lösningar.

Använd fälten:

- beslut,
- bakgrund,
- alternativ,
- motivering,
- konsekvens,
- ägare,
- datum,
- koppling till krav/test.

## Övning 3: Hitta överdokumentation

Granska en befintlig kravmall, backloggmall eller spårbarhetsmatris.

Markera vilka fält som:

- används ofta,
- används ibland,
- nästan aldrig används.

Föreslå en förenklad version som fortfarande ger tillräcklig spårbarhet.

## Reflektionsfråga

Vilken typ av spårbarhet saknas oftast i din organisation: behovskoppling, kravkoppling, styrningskoppling, verifieringskoppling eller beslutsspår?
