# Övningar till kapitel 3: Från kravspecifikation till levande kravunderlag

## Övning 1: Kartlägg ditt nuvarande kravunderlag

Välj ett aktuellt eller nyligen avslutat initiativ. Lista alla platser där kravkunskap finns.

Exempel:

- kravspecifikation,
- backlogg,
- processkartor,
- mötesanteckningar,
- beslutslogg,
- testfall,
- regelunderlag,
- mejltrådar,
- systemdokumentation,
- förvaltningsdokument.

Markera sedan:

| Underlag | Används aktivt? | Innehåller viktig kravkunskap? | Risk/problem |
|---|---|---|---|
| | | | |

Reflektera:

- Var finns den viktigaste kunskapen?
- Vilket underlag är mest föråldrat?
- Var upprepas samma information?
- Vilken information skulle vara svårast att hitta för en ny teammedlem?

## Övning 2: Sortera kravkunskap

Välj fem kravrelaterade uppgifter och sortera dem i tabellen.

| Uppgift/information | Stabilt underlag | Arbetsnära underlag | Utforskande underlag | Kommentar |
|---|---|---|---|---|
| | | | | |

Frågor:

- Vad är redan beslutat?
- Vad behövs för nästa utvecklingssteg?
- Vad är fortfarande osäkert?
- Vad behöver vara begripligt om sex månader?

## Övning 3: Skapa en minikarta

Skapa en enkel karta över var ett team hittar:

- mål och effekt,
- prioriterade krav,
- verksamhetsregler,
- öppna frågor,
- beslut,
- acceptanskriterier,
- testexempel.

Skriv sedan en kort instruktion till en ny teammedlem:

> “Så här hittar du rätt kravunderlag i vårt initiativ ...”

## Fördjupningsövning

Ta en gammal kravspecifikation och välj tre avsnitt som skulle kunna brytas ut till mer levande artefakter.

Exempel:

| Avsnitt i kravspecifikation | Ny artefakt | Varför passar det bättre där? |
|---|---|---|
| | | |

Avsluta med att identifiera en risk med att bryta ut informationen och hur den risken kan hanteras.
