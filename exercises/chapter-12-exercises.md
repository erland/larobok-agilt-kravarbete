| Kravfråga | Vad är oklart? | Vem behöver förstå/besluta? | Lämpligt verktyg | Förväntad output |
|---|---|---|---|---|
| 1 | | | | |
| 2 | | | | |
| 3 | | | | |

Reflektera: Valde du verktyg utifrån situationen, eller utifrån vad du brukar göra?

## Övning 2: Redo nog

Ta en backloggpost eller ett krav som snart ska utvecklas. Bedöm det mot checklistan:

- Syftet är begripligt.
- Målgrupp eller aktör är tydlig.
- Funktionellt beteende är tillräckligt beskrivet.
- Viktiga regler och undantag är kända eller markerade som öppna.
- Acceptanskriterier eller testexempel finns.
- Beroenden är synliga.
- Produktägaren kan prioritera.
- Teamet kan ställa rimliga följdfrågor.
- Det är tydligt vad som inte ingår.
- Öppna frågor har ägare.

Skriv sedan: Är kravet redo nog för utveckling, redo nog för fördjupning eller inte redo?

## Fördjupning: Din egen verktygslåda

Välj fem verktyg från kapitlet som skulle göra störst nytta i din organisation. För varje verktyg, skriv:
